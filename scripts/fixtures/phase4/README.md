# Phase 4 local app evidence

`local-app/acceptance.json` describes the manual graph/editor acceptance. `workflows/` preserves
three immutable versions of the shell graph, its final draft, an invalid plan draft and a saved
empty draft. `runs/` contains the completed shell run, including preview/runtime preflight and
per-visit logs. These are local fixture records, not instructions to execute the example scripts.
The temporary repository paths identify the original measurement; no model was invoked.
